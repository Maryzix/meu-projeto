
Questão 7. 

Explique com suas palavras qual problema o Facade resolve. Se quiser, use o exemplo do síndico do condomínio ou crie outro.

O padrão Facade resolve o problema de precisar interagir com várias classes e métodos para realizar uma única tarefa. Ele cria uma classe que simplifica esse processo, oferecendo um único ponto de acesso para o sistema.
